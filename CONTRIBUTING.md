# Contributing to HealthMind

Thank you for considering contributing to HealthMind!

## Getting Started

1. Fork the repo
2. Clone your fork
3. Install dependencies: `pip install -r requirements.txt`
4. Create a feature branch from `main`

## Development

- **Python**: Follow PEP 8
- **Model changes**: Document your training/evaluation setup
- **Config**: Add any new config values to `.env.template`

## PR Process

1. Test your changes locally
2. Update documentation if needed
3. Create a PR using the template
4. Keep PRs focused on a single improvement

## Data Privacy

HealthMind processes health-related data. Do not commit:
- Real patient data
- API keys or credentials
- Model weights (use `.gitignore`)
