# EcoLife 智能助手技术文档

## 1. 概述

EcoLife 智能助手是一个基于 LangChain + LangGraph + 通义千问的对话式 AI 助手，专为碳足迹管理场景设计。助手可以调用预定义的工具函数，帮助用户查询碳排放数据、获取减碳建议等。

## 3. 核心组件

### 3.1 LLM 配置

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="qwen3.5-plus",
    api_key=DASHSCOPE_API_KEY,
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    temperature=0.7,
)
```

**配置说明**:
- **model**: `qwen3.5-plus` - 通义千问 3.5 Plus 版本
- **base_url**: 阿里云 DashScope 兼容 OpenAI 的 API 端点
- **temperature**: 0.7 - 平衡创造性和准确性

### 3.2 Agent 创建

```python
from langgraph.prebuilt import create_react_agent
from langgraph.checkpoint.memory import MemorySaver

# 创建记忆模块
memory = MemorySaver()

# 系统提示
system_message = "你是一个专业的碳足迹助手，帮助用户查询碳排放、获取减碳建议。使用中文回复。"

# 创建 Agent
agent = create_react_agent(
    model=llm,
    tools=tools,
    prompt=system_message,
    checkpointer=memory,
)
```

### 3.3 工具定义

智能助手包含 5 个核心工具：

| 工具名称 | 功能 | 输入参数 | 返回示例 |
|---------|------|---------|---------|
| `get_current_carbon` | 获取今日总碳排放量 | 无 | `{"carbon": 5.2}` |
| `predict_carbon` | 预测指定日期碳排放 | `date`, `behavior` | `{"predicted": 6.8, "unit": "kg CO₂e"}` |
| `explain_carbon` | 解释碳排放构成 | `date` | `{"factors": {...}, "total": 6.6}` |
| `get_recommendations` | 获取减碳建议 | `date` | `{"recommendations": [...]}` |
| `query_strategy` | 查询减碳策略 | `scene` | `{"strategies": [...]}` |

工具定义位于 `src/agent/tools.py`

## 4. API 接口

### 4.1 启动 API 服务

```bash
# 默认 localhost:8000
python -m src.agent.debug_api

# 或指定主机和端口
python -m src.agent.debug_api 0.0.0.0 8000
```

### 4.2 接口列表

#### GET /health
检查服务状态

**响应示例**:
```json
{
  "status": "ok",
  "agent_ready": true
}
```

#### GET /tools
获取可用工具列表

**响应示例**:
```json
{
  "success": true,
  "tools": [
    {"name": "get_current_carbon", "description": "获取用户今日已产生的总碳排放量"},
    {"name": "predict_carbon", "description": "预测特定日期的碳排放量"},
    ...
  ]
}
```

#### POST /chat
发送聊天消息

**请求示例**:
```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "我今天碳排多少？", "thread_id": "user1"}'
```

**响应示例**:
```json
{
  "success": true,
  "response": "根据记录，您今天的碳排放量为 XX kg...",
  "error": null
}
```

## 5. 使用示例

### 5.1 Python 调用

```python
from src.agent.debug_api import chat, list_tools

# 查看工具
tools = list_tools()
print(tools)

# 发送消息
response = chat("我今天碳排多少？", thread_id="user1")
print(response["response"])

# 继续对话（保持 thread_id 保持上下文）
response = chat("那明天呢？", thread_id="user1")
print(response["response"])
```

### 5.2 cURL 调用

```bash
# 健康检查
curl http://localhost:8000/health

# 获取工具列表
curl http://localhost:8000/tools

# 发送消息
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "有什么减碳建议吗？", "thread_id": "session1"}'
```

### 5.3 JavaScript 调用

```javascript
// 发送消息
async function sendMessage(message, threadId = 'default') {
  const response = await fetch('http://localhost:8000/chat', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      message: message,
      thread_id: threadId
    })
  });
  return await response.json();
}

// 使用
const result = await sendMessage("我今天碳排多少？", "user1");
console.log(result.response);
```

## 6. 对话记忆

智能助手支持多轮对话记忆，通过 `thread_id` 参数区分不同会话：

```python
# 会话 1
chat("我今天碳排多少？", thread_id="user1")
chat("那昨天呢？", thread_id="user1")  # 保持上下文

# 会话 2
chat("我今天碳排多少？", thread_id="user2")  # 新会话，无上下文
```

**记忆存储**: 使用 LangGraph 的 `MemorySaver` 模块，记忆存储在内存中。

## 7. 常见问题排查

### 7.1 Agent 初始化失败

**错误**: `Failed to create agent instance`

**排查步骤**:
1. 检查 `.env` 文件中 `DASHSCOPE_API_KEY` 是否配置
2. 确认依赖已安装：`pip install langgraph langchain-openai langchain-core`
3. 检查工具定义是否正确：`python -c "from src.agent.tools import get_all_tools; print(get_all_tools())"`

### 7.2 API 调用返回 401

**错误**: `401 Unauthorized` 或 `InvalidApiKey`

**解决方案**:
1. 访问 https://dashscope.console.aliyun.com/ 检查 API Key 状态
2. 确认账户有足够余额
3. 检查 API Key 格式是否正确（应以 `sk-` 开头）

### 7.3 工具调用失败

**错误**: 工具返回空数据或错误

**排查步骤**:
1. 检查后端服务是否启动（用户系统、碳引擎等）
2. 验证用户是否已登录并有数据
3. 查看日志输出获取详细错误信息

### 7.4 响应速度慢

**可能原因**:
1. 网络延迟（调用阿里云 API）
2. 模型推理时间
3. 工具执行时间

**优化建议**:
1. 使用更快的网络连接
2. 考虑使用流式响应（待实现）
3. 缓存常用查询结果
