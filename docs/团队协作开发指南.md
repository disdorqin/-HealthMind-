## 1. 项目简介

### 1.1 项目名称
**EcoLife** - 个人碳足迹预测与管理平台

### 1.2 项目定位
计算机设计大赛参赛作品，一个面向个人碳足迹管理的智能预测与决策支持平台。

### 1.3 核心功能
- 🔮 **多模型融合预测**：集成 LSTM、GRU、XGBoost、Moirai 四种模型
- 📊 **Stacking 融合机制**：简单平均 + 元学习融合
- 🌿 **智能碳管理**：碳预算、碳积分、荣誉体系
- 💡 **个性化减碳建议**：饮食、出行、用能建议

### 1.4 技术亮点
| 模型 | 特点 | 当前表现 |
|------|------|----------|
| LSTM | 双向 LSTM，捕捉时序依赖 | R² ≈ -0.02 |
| GRU | 门控循环单元，训练高效 | R² ≈ -0.02 |
| XGBoost | 梯度提升树，特征重要性 | R² ≈ 0.98 ⭐ |
| Moirai | 时序基础模型，零样本学习 | R² ≈ -0.02 |
| **Stacking 融合** | 元模型学习最优权重 | R² ≈ 0.64 |

## 4. 模型优化指南

### 4.1 使用 main.py 进行训练

#### 快速开始
```bash
# 交互模式（推荐新手）
python main.py

# 命令行模式
python main.py --train --models 1      # 训练 LSTM
python main.py --train --models 2      # 训练 GRU
python main.py --train --models 1,2    # 训练 LSTM+GRU
python main.py --train --stack --models 1,2,3,4  # 全模型融合
```

#### 参数说明
| 参数 | 说明 | 示例 |
|------|------|------|
| `--train` | 训练模式 | `python main.py --train` |
| `--stack` | 启用 Stacking 融合 | `--train --stack` |
| `--models` | 模型选择 (1=LSTM, 2=GRU, 3=XGBoost, 4=Moirai) | `--models 1,3` |
| `--interactive` | 强制交互模式 | `--interactive` |

### 4.2 模型文件位置与参数说明

#### 📁 LSTM 模型
**文件位置**：`src/models/lstm_model.py`

**关键参数**（第 52-60 行）：
```python
def __init__(
    self,
    input_dim: int = 10,        # 输入特征维度
    hidden_dim: int = 128,      # 隐藏层维度（可调）
    num_layers: int = 2,        # LSTM 层数（可调）
    learning_rate: float = 1e-3, # 学习率（可调）
    name: str = "lstm",
):
```

**训练参数**（第 68-75 行）：
```python
def train(
    self,
    X_train: np.ndarray,
    y_train: np.ndarray,
    X_val: Optional[np.ndarray] = None,
    y_val: Optional[np.ndarray] = None,
    epochs: int = 100,          # 训练轮数（可调）
    batch_size: int = 32,       # 批大小（可调）
    patience: int = 15,         # 早停耐心值（可调）
    save_path: str = "models/checkpoints/lstm_best.pth",
    **kwargs: Any,
) -> Dict[str, Any]:
```

**优化建议**：
| 参数 | 当前值 | 建议尝试范围 | 说明 |
|------|--------|--------------|------|
| `hidden_dim` | 128 | 64, 128, 256, 512 | 隐藏层维度，越大模型越复杂 |
| `num_layers` | 2 | 1, 2, 3 | 层数越多，捕捉长期依赖能力越强 |
| `learning_rate` | 0.001 | 0.0001, 0.001, 0.01 | 学习率，太小收敛慢，太大可能不收敛 |
| `epochs` | 100 | 50, 100, 200 | 训练轮数 |
| `batch_size` | 32 | 16, 32, 64 | 批大小 |
| `patience` | 15 | 10, 15, 20 | 验证集 loss 不下降多少轮后早停 |

**修改示例**：
```python
# 修改前
hidden_dim: int = 128,
num_layers: int = 2,
learning_rate: float = 1e-3,

# 修改后（示例：增大模型容量）
hidden_dim: int = 256,
num_layers: int = 3,
learning_rate: float = 5e-4,
```

#### 方案二：Gradio 界面（推荐 ⭐⭐⭐⭐）

**优点**：
- 更简洁的交互界面
- 支持 Hugging Face Spaces 部署
- 适合机器学习模型展示

**示例代码**（新建 `gradio_app.py`）：
```python
import gradio as gr
import numpy as np
from src.services.prediction_service import PredictionService

predictor = PredictionService()
predictor.load_models()

def predict_carbon_footprint(model_choice, days):
    """预测未来碳排放"""
    preds = predictor.predict_next_cycle("data/personal_carbon_footprint_behavior.csv")
    
    if model_choice == "LSTM":
        result = preds.get('lstm', 0)
    elif model_choice == "XGBoost":
        result = preds.get('xgboost', 0)
    else:
        result = preds.get('ensemble_meta', 0)
    
    # 生成预测曲线
    dates = [f"Day {i+1}" for i in range(days)]
    values = [result + np.random.normal(0, 1) for _ in range(days)]
    
    return list(zip(dates, values))

demo = gr.Interface(
    fn=predict_carbon_footprint,
    inputs=[
        gr.Dropdown(["LSTM", "XGBoost", "Ensemble"], label="选择模型"),
        gr.Slider(7, 30, value=7, label="预测天数")
    ],
    outputs="json",
    title="🌿 EcoLife 碳足迹预测",
    description="选择模型并设置预测天数，获取未来碳排放预测"
)

demo.launch()
```

**部署**：
- Hugging Face Spaces: https://huggingface.co/spaces

#### 方案三：Vue/React + Flask 前后端分离（推荐 ⭐⭐⭐）

**优点**：
- 专业级前端展示
- 可定制化程度高
- 适合制作精美演示视频

**架构**：
```
前端 (Vue/React)  ←→  后端 (Flask API)  ←→  模型层
```

**后端 API 示例**（新建 `api_server.py`）：
```python
from flask import Flask, jsonify, request
from flask_cors import CORS
from src.services.prediction_service import PredictionService

app = Flask(__name__)
CORS(app)

predictor = PredictionService()
predictor.load_models()

@app.route('/api/predict', methods=['GET'])
def predict():
    model = request.args.get('model', 'ensemble')
    days = int(request.args.get('days', 7))
    
    preds = predictor.predict_next_cycle("data/personal_carbon_footprint_behavior.csv")
    
    return jsonify({
        'model': model,
        'prediction': preds.get(model, preds.get('ensemble_meta', 0)),
        'all_predictions': preds
    })

@app.route('/api/metrics', methods=['GET'])
def get_metrics():
    return jsonify({
        'lstm': {'r2': -0.02, 'mae': 2.01},
        'xgboost': {'r2': 0.98, 'mae': 0.25},
        'ensemble': {'r2': 0.64, 'mae': 1.21}
    })

if __name__ == '__main__':
    app.run(debug=True, port=5000)
```

**前端示例**（Vue 组件）：
```vue
<template>
  <div class="eco-life">
    <h1>🌿 EcoLife 碳足迹预测</h1>
    
    <select v-model="selectedModel">
      <option value="lstm">LSTM</option>
      <option value="xgboost">XGBoost</option>
      <option value="ensemble">融合模型</option>
    </select>
    
    <button @click="fetchPrediction">预测</button>
    
    <div class="result">
      <h3>预测结果：{{ prediction }} kg</h3>
    </div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      selectedModel: 'ensemble',
      prediction: 0
    }
  },
  methods: {
    async fetchPrediction() {
      const response = await fetch(`/api/predict?model=${this.selectedModel}`)
      const data = await response.json()
      this.prediction = data.prediction
    }
  }
}
</script>
```
